# Fooddee Clean Landing Page

This is a cleaned and organized version of the Fooddee landing page.

## Folder structure

```text
fooddee-clean-site/
├─ index.html
├─ css/
│  └─ styles.css
├─ js/
│  └─ main.js
└─ assets/
   ├─ brand/
   ├─ icons/
   ├─ decor/
   └─ food/
      ├─ categories/
      └─ dishes/
```

## How to run

Open `index.html` directly in your browser, or open the folder in VS Code and run with Live Server.

## What was cleaned

- Removed old mixed/messy paths like `HTML/index.html`, `javascript/script.js`, and wrong `style.css` linking.
- Removed the `.git` folder from the shared zip.
- Organized images into brand, icons, decor, categories, and dishes.
- Rebuilt the landing page to match the reference Fooddee UI style.
- Added responsive mobile layout.
- Added small JS features: search filter, category filter, add-to-cart count, subscribe toast.
